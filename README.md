### Frontend
- **Frameworks:** Angular 22 (Standalone, Zoneless, Signal-first), TypeScript 6
- **Styling:** Bootstrap 5 RTL, CSS Custom Properties, Responsive Design
- **State Management:** NgRx SignalStore, Signals, computed(), resource()
- **Forms:** Signal Forms (Angular 22 native)
- **Real-time:** SignalR (@microsoft/signalr)

### API & Integration
- **HTTP:** Angular HttpClient (typed), DTO → Adapter → UI Model pattern
- **Auth:** JWT Bearer tokens, HTTP Interceptors
- **Backend Awareness:** ASP.NET Core Web API (.NET 8/9)

### AI Integration
- **LLM:** AI Prompt Search, Chatbot Assistant
- **RAG:** Vector DB + MCP servers
- **Agents:** KYB Verification, Matching, Fraud Detection

### Tools & Workflow
- **Version Control:** Git, GitHub
- **Testing:** Vitest, Angular Testing Library
- **IDEs:** VS Code
- **Design:** Figma (pixel-perfect implementation)
